# 免费部署平台指南（亲测版）

> 本项目「驴链 DonkeyTrace」实际用过的部署平台整理：Cloudflare Pages（前端托管）、
> Aiven（云数据库）、GitHub（代码托管）。步骤来自真实操作经历，含踩坑记录；
> 文末附尝试过但放弃的平台简表，避免后人重踩。

## 一、Cloudflare Pages（前端静态托管 ✅ 核心平台）

**官网**：https://pages.cloudflare.com ｜ **送的域名**：`项目名.pages.dev` ｜ **费用**：免费

### 注册（3 分钟）

1. 打开 cloudflare.com → "Sign up" → 邮箱注册（QQ/163/Gmail 均可）
2. 邮箱验证后即可使用控制台（dash.cloudflare.com）

### 部署前端（两种方式）

**方式 A：直接上传（本项目用的，最简单，不需要连 Git）**

1. 本地先把前端构建出静态文件：`npm run build`，得到 `dist` 文件夹
   （本项目用的是演示模式构建：`VITE_API_MODE=mock npx vite build --outDir dist-mock --emptyOutDir`）
2. Cloudflare 控制台 → **Workers & Pages** → "Create application" → 选 **Pages** 标签（别点进 Workers 的上传入口！本项目就走偏过一次）
3. 选 **"Upload assets"（直接上传）** → 起个名字（如 `donkey-trace`）
4. 把 **dist 文件夹**（不是项目根目录！）拖进上传框 → Deploy
5. 几十秒后得到 `donkey-trace.pages.dev`，自带 HTTPS，全球 CDN 可访问

**方式 B：连 GitHub 仓库自动构建**（提交代码自动重新部署，本项目装了 Cloudflare GitHub App 备用）

### 绑定自定义域名

1. Pages 项目 → "Custom domains" → 添加（如 `www.lvlianchain.dpdns.org`）
2. 若域名已接入 Cloudflare DNS，证书自动签发，几分钟生效

### 踩坑记录

| 坑 | 说明 |
| --- | --- |
| Pages 和 Workers 入口容易点混 | 传静态站一定走 **Pages → Upload assets**，Workers 的"上传并部署"是传 Worker 脚本的 |
| 拖错文件夹 | 要拖**构建产物 dist**（特征：里面是 index.html + assets/），不是项目源码根目录 |
| 前端路由 | 项目用了 vue-router **hash 模式**（`/#/路径`），静态托管零适配；history 模式才需要配 _redirects |

## 二、Aiven for MySQL（云数据库 ✅）

**官网**：https://aiven.io ｜ **免费额度**：1 核 / 1GB 内存 / 1GB 存储，永久免费 ｜ **费用**：免费

### 注册与建库（15 分钟）

1. 打开 aiven.io → "Get started for free" → 邮箱或 Google/GitHub 登录
2. "Create service" → 选 **MySQL** → 选 Free 计划 → 云厂商和区域随意（选了 DigitalOcean）
3. 等几分钟服务启动（状态变 RUNNING）
4. "Connection information" 页抄下：**Host、Port、User（avnadmin）、Password**——⚠️ 主机名要**点复制按钮粘贴原文**，别从截图辨认（本项目把 `e661.l` 看成 `e6611` 排查了半天）
5. 连接导入数据：本地 `mysql.exe` 连上去执行建库 SQL 即可，连接串必须带 `sslMode=REQUIRED`（Aiven 强制 TLS）：
   ```
   mysql -h mysql-xxxx.aivencloud.com -P 27912 -u avnadmin -p --ssl-mode=REQUIRED
   ```

### 踩坑记录

| 坑 | 说明 |
| --- | --- |
| **控制台大陆访问不稳** | 本机实测控制台 SPA 经常打不开（换网络出口后成功）；数据连接本身不受影响 |
| **主机名长且易抄错** | 随机高位端口 + 长主机名，务必复制粘贴 |
| **长期闲置会断电** | 空闲太久服务转 Powered off，数据不丢，控制台点 "Power on" 唤醒即可 |
| 后端连接串 | Spring Boot 的 JDBC 串记得带 `sslMode=REQUIRED`，否则连不上 |

## 三、GitHub（代码托管 ✅）

**官网**：https://github.com ｜ **费用**：免费（公开/私有仓库都免费）

### 步骤

1. 注册账号 → 右上角 "+" → "New repository" → 起名（`donkey-traceability`）→ Public/Private 均可 → 不要勾选初始化 README
2. 本地推送：
   ```
   git init
   git add .
   git commit -m "init"
   git remote add origin https://github.com/用户名/donkey-traceability.git
   git push -u origin main
   ```
3. 推送会弹浏览器授权（Git Credential Manager 自动处理，授权一次后续免密）
4. `.gitignore` 先写好再提交（node_modules/dist/target/交付包等都要排除，否则仓库臃肿）

**附带价值**：装 Cloudflare GitHub App 后，Pages 可自动从仓库构建部署（CI/CD 加分点）。

## 四、尝试过但放弃的平台（避坑清单 ⚠️）

| 平台 | 用途 | 结果 | 原因 |
| --- | --- | --- | --- |
| **Render** | 后端容器托管 | ❌ 放弃 | 2026 年起新账号**强制绑卡**，绕不过 |
| **Koyeb** | 后端容器托管 | ❌ 放弃 | 控制台 `api.koyeb.com` 在国内网络**被墙**，SPA 白屏；换热点也断 |
| **TiDB Cloud** | 云 MySQL | ❌ 放弃 | 控制台大陆打不开（换 Aiven 成功） |
| **Sealos** | 容器托管 | 未采用 | 国内丝滑、不绑卡，但免费仅 7 天试用，之后 $7/月——与"免费几个月"诉求冲突 |
| **阿里云试用** | 后端/域名 | 未采用 | 需实名 + 绑支付方式才能开通，与"不折腾"诉求冲突 |

> 后端部署若日后想做：Dockerfile 已备好（backend/Dockerfile + maven-settings-aliyun.xml），
> Sealos 或国内云均可一键续上，详见 `docs/线上部署指南.md`。
