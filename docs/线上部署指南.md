## 1. 线上演示站是怎么上线的（实录，可复现）

1. **构建自包含演示版前端**（在 `admin-web/` 下）：
   ```
   set VITE_API_MODE=mock && npx vite build --outDir dist-mock --emptyOutDir
   ```
   产物 `dist-mock/`（43 文件 / 约 2.8MB）：hash 路由 + 内存演示数据层，静态托管零适配。
2. **Cloudflare Pages 上传**：dash.cloudflare.com → Workers & Pages → Create → **Pages** →
   **Upload assets**（不要走 Git 构建、不要进 Workers 上传页）→ 项目名 `donkey-trace` →
   拖入 `dist-mock` 文件夹 → Deploy → 得到 `https://donkey-trace.pages.dev`。
   - 坑①：拖文件夹要拖 **dist-mock**（特征：index.html + assets/，无 package.json），
     不要拖 admin-web 源码根目录。
3. **绑定自有域名（DigitalPlat 免费域名）**：
   - Pages 项目 → Custom domains → 添加 `www.lvlianchain.dpdns.org`
   - DigitalPlat 控制台 → DNS 记录 → 添加 CNAME：
     - 名称：`www`（**不能用 @**——`CNAME records cannot be created at the zone apex`，RFC 不允许）
     - 值：`donkey-trace.pages.dev.` ← **结尾必须带英文句点**，否则会被拼成
       `donkey-trace.pages.dev.lvlianchain.dpdns.org.`（坑②，实测踩过）
   - 几分钟内证书签发生效。

## 常见问题

- **CNAME 报 apex 错误**：CNAME 只能挂在子域（用 www），apex 只能 A 记录或 ALIAS。
- **CNAME 值被拼后缀**：值结尾补英文句点。
- **SPA 控制台打不开**：分别测试主站域名与 API 子域名的连通性（Koyeb 教训：
  `app.koyeb.com` 200 但 `api.koyeb.com` 000 时，页面必然白屏）。
- **前端白屏/接口 404**：检查 `VITE_API_BASE` 是否以后端地址 + `/api` 结尾。
- **跨域报错**：后端已配置 allowedOriginPatterns("*")，一般不会出现；注意 http/https 混用
  （https 页面请求 http 接口会被浏览器拦截，后端域名需同为 https）。
