# 线上部署指南（免费方案 · 作业加分项）

> 目标架构：前端 Cloudflare Pages + 后端 Render + 数据库 Aiven for MySQL（永久免费）+ 域名 lvlianchain.dpdns.org
> 全部免费档，三家平台均支持 GitHub 账号直接登录。
> （原 TiDB Cloud 方案因大陆访问控制台过慢已弃用，2026-09-23 改为 Aiven）

## 2. Aiven：建免费 MySQL 数据库

1. aiven.io → 右上角 **Sign up** → **Continue with GitHub** 授权登录（免绑卡）
2. 首次登录按提示创建一个 **Project**（名字随意，如 `donkey-trace`）
3. Create service → 选 **MySQL** → 计划选 **Free**（Free tier）
   - Cloud & region：如果有 Singapore/asia-southeast1 就选它；没有就默认
   - Service name：`donkey-mysql`
4. 等 3~5 分钟，状态变 **Running**
5. 进入服务 Overview → **Connection information**，抄下 5 样东西：
   - **Host**（形如 `mysql-xxxx-donkey-trace.a.aivencloud.com`）
   - **Port**（Aiven 是随机高位端口，如 `12345`，不是 3306）
   - **User**（默认 `avnadmin`）
   - **Password**（点眼睛图标可见）
   - 数据库名：默认 `defaultdb`（导入时我们会建 `donkey_trace`）
6. 把 Host / Port / User / Password 发给 AI 助手，由助手用本机 MySQL 客户端
   （TLS 必需）一键导入 `backend/database/database.sql` 的 19 张表 + 演示数据
7. 注意：免费服务**长期无访问会被自动断电**，控制台一键开机即可，数据不丢；
   答辩/演示前先访问一次系统即可保持唤醒

## 3. Render：部署后端

1. render.com → GitHub 登录 → New → **Web Service** → 连接你的 GitHub 仓库
2. 配置：
   - **Runtime: Docker**（仓库已有 `backend/Dockerfile`；Root Directory 填 `backend`）
   - Instance Type: **Free**
   - Environment Variables:
     | Key | Value |
     |-----|-------|
     | DB_URL | `jdbc:mysql://<Host>:<Port>/donkey_trace?sslMode=REQUIRED&serverTimezone=Asia/Shanghai&characterEncoding=utf8` |
     | DB_USER | `avnadmin` |
     | DB_PASS | Aiven 密码 |
3. Deploy 等待 5~10 分钟（云端构建 Maven），成功后得到 `https://donkey-trace-backend-xxxx.onrender.com`
4. 验证：浏览器访问 `https://...onrender.com/api/auth/login`（POST 不行就先看部署日志）
   - 免费档 15 分钟无流量会休眠，首次唤醒要 30~50 秒，属正常

## 4. Cloudflare Pages：部署前端

1. dash.cloudflare.com → Workers & Pages → Create → **Pages** → Connect to Git → 选你的仓库
2. 构建配置：
   - **Root Directory: `admin-web`**
   - Build command: `npm run build`
   - Output: `dist`
   - 环境变量：`VITE_API_BASE = https://donkey-trace-backend-xxxx.onrender.com/api`（第 3 步得到的后端地址 + `/api`）
3. 部署成功得到 `https://<项目名>.pages.dev`，此时系统已可公网访问

## 5. 绑定自有域名

1. Cloudflare 添加站点 `dpdns.org`? —— 免费子域名无法整体托管；改用 **CNAME 方式**：
   - Pages 项目 → Custom domains → 添加 `lvlianchain.dpdns.org`
   - Cloudflare 会给出目标值（形如 `<项目>.pages.dev`）
2. 回 DigitalPlat 控制台 → 管理 lvlianchain.dpdns.org → DNS 记录 → **添加记录**：
   - 类型 `CNAME`，名称 `@`（或留空），值 `<项目>.pages.dev`，TTL 默认
3. 等证书签发（几分钟），访问 `https://lvlianchain.dpdns.org` 即为线上系统

## 常见问题

- **Render 构建超时**：Docker 首次拉 Maven 依赖较慢，重试一次即可
- **Aiven 连接失败**：确认 JDBC 串带 `sslMode=REQUIRED`（Aiven 强制 TLS），端口用 Connection information 给的高位端口（不是 3306）
- **Aiven 服务显示 Powered off**：免费档长时间无访问被断电，Overview 页点 Power on，数据不丢
- **前端白屏/接口 404**：检查 VITE_API_BASE 是否以后端地址 + `/api` 结尾
- **跨域报错**：后端已配置 allowedOriginPatterns("*")，一般不会出现；若出现检查是否走了 http/https 混用
