# 线上部署指南（免费方案 · 作业加分项）

> 目标架构：前端 Cloudflare Pages + 后端 Render + 数据库 TiDB Cloud（MySQL 兼容）+ 域名 lvlianchain.dpdns.org
> 全部免费档，三家平台均支持 GitHub 账号直接登录。

## 0. 需要注册的账号（GitHub 一键登录即可）

| 平台 | 网址 | 用途 |
|------|------|------|
| GitHub | 已有 | 代码托管 + 三家平台登录凭据 |
| Render | render.com | 跑 Spring Boot 后端（免费 Web Service） |
| TiDB Cloud | tidbcloud.com | 免费 MySQL 兼容数据库（Serverless，5GB） |
| Cloudflare | dash.cloudflare.com | Pages 前端托管 + 域名 DNS |

## 1. 代码上 GitHub

```bash
cd backend 项目根目录（donkey-traceability）
git init && git add . && git commit -m "init"
# GitHub 网页上新建仓库（如 donkey-traceability），然后：
git remote add origin https://github.com/<你的用户名>/donkey-traceability.git
git push -u origin main
```

> 注意 .gitignore：排除 admin-web/node_modules、admin-web/dist、backend/target、**application.yml 里的本地密码无敏感性（root/root 演示库）**，但上传前建议把数据库密码改为环境变量形式（已改好，见 application.yml 的 DB_URL/DB_USER/DB_PASS）。

## 2. TiDB Cloud：建免费数据库

1. tidbcloud.com → GitHub 登录 → 创建 Organization
2. Create Cluster → 选 **Serverless**（免费）→ 区域选 Singapore/Tokyo（离大陆近）
3. 建好后进入 Overview → **Connect** → 复制连接串，形如：
   `mysql://<user>:<pass>@gateway01.<region>.prod.aws.tidbcloud.com:4000/test`
4. 用 MySQL 客户端（Navicat/DBeaver，端口 4000，需 TLS）连上后执行 `backend/database/database.sql` 导入 19 张表和种子数据
   - 若单文件导入超时，可分表执行；TiDB 对本项目的 DDL/DML 完全兼容

## 3. Render：部署后端

1. render.com → GitHub 登录 → New → **Web Service** → 连接你的 GitHub 仓库
2. 配置：
   - **Runtime: Docker**（仓库已有 `backend/Dockerfile`；Root Directory 填 `backend`）
   - Instance Type: **Free**
   - Environment Variables:
     | Key | Value |
     |-----|-------|
     | DB_URL | `jdbc:mysql://gateway01.<region>.prod.aws.tidbcloud.com:4000/donkey_trace?sslMode=REQUIRED&serverTimezone=Asia/Shanghai&characterEncoding=utf8` |
     | DB_USER | TiDB 用户名 |
     | DB_PASS | TiDB 密码 |
3. Deploy 等待 5~10 分钟（云端构建 Maven），成功后得到 `https://donkey-trace-backend-xxxx.onrender.com`
4. 验证：浏览器访问 `https://...onrender.com/api/auth/login`（POST 不行就先看部署日志）
   - 免费档 15 分钟无流量会休眠，首次唤醒要 30~50 秒，属正常

## 4. Cloudflare Pages：部署前端

1. dash.cloudflare.com → Workers & Pages → Create → **Pages** → Connect to Git → 选你的仓库
2. 构建配置：
   - **Root Directory: `admin-web`**
   - Build command: `npm run build`
   - Output: `dist`
   - 环境变量：`VITE_API_BASE = https://donkey-trace-backend-xxxx.onrender.com/api`（第 3 步得到的后端地址 + `/api`）
3. 部署成功得到 `https://<项目名>.pages.dev`，此时系统已可公网访问

## 5. 绑定自有域名

1. Cloudflare 添加站点 `dpdns.org`? —— 免费子域名无法整体托管；改用 **CNAME 方式**：
   - Pages 项目 → Custom domains → 添加 `lvlianchain.dpdns.org`
   - Cloudflare 会给出目标值（形如 `<项目>.pages.dev`）
2. 回 DigitalPlat 控制台 → 管理 lvlianchain.dpdns.org → DNS 记录 → **添加记录**：
   - 类型 `CNAME`，名称 `@`（或留空），值 `<项目>.pages.dev`，TTL 默认
3. 等证书签发（几分钟），访问 `https://lvlianchain.dpdns.org` 即为线上系统

## 常见问题

- **Render 构建超时**：Docker 首次拉 Maven 依赖较慢，重试一次即可
- **TiDB 连接失败**：确认连接串带 `sslMode=REQUIRED`，端口 4000（不是 3306）
- **前端白屏/接口 404**：检查 VITE_API_BASE 是否以后端地址 + `/api` 结尾
- **跨域报错**：后端已配置 allowedOriginPatterns("*")，一般不会出现；若出现检查是否走了 http/https 混用
