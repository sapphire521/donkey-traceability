# 免费域名注册指南（亲测版）

> 以本项目「驴链 DonkeyTrace」实际使用的 **DigitalPlat FreeDomain（dpdns.org）** 为主，
> 注册步骤全部来自真实操作经历（2026-09），含踩坑记录。文末附其他免费域名渠道简表。

---

## 一、DigitalPlat FreeDomain（本项目在用 ✅）

**官网入口**：https://dig.ug （DigitalPlat FreeDomain 免费域名服务）
**本项目注册的域名**：`lvlianchain.dpdns.org`
**费用**：完全免费，无隐藏收费，无需信用卡

### 可选后缀

`dpdns.org`、`qzz.io`、`xx.kg`、`mywire.org`、`us.kg` 等（列表随时间可能调整，注册页以实际显示为准）

### 注册步骤（约 10 分钟）

1. **打开官网** → 点 "Register" / "Dashboard" 进入注册面板（`dash.domain.digitalplat.org`）
2. **注册账号**：邮箱 + 密码 → 收验证邮件 → 点链接激活（QQ 邮箱、163、Gmail 都可以收）
3. **登录后** → 左侧 "My Account" / "Create Domain"
4. **申请域名**：
   - 输入想要的名字（本项目填的是 `lvlianchain`）
   - 下拉选择后缀（本项目选 `dpdns.org`）
   - DNS 服务器一栏：可以直接填 Cloudflare 分配的两个 NS 地址（推荐，见下文绑定 Cloudflare），也可以留空用自带 DNS 面板
5. **提交后等审核**：一般几分钟到几小时，通过后收到开通邮件，域名即可解析
6. **添加解析记录**：进 DNS 管理面板（自带面板或 Cloudflare）加记录

### 绑定 Cloudflare Pages（本项目做法 ⭐ 推荐）

1. 先把域名接入 Cloudflare：Cloudflare 控制台 → "Add a site" → 输入 `lvlianchain.dpdns.org` → 选 Free 套餐 → Cloudflare 会给两个 NS 地址
2. 回 DigitalPlat 面板把这两个 NS 填上，等待生效（几分钟到几小时）
3. Cloudflare Pages 项目 → "Custom domains" → 添加自定义域 → CF 自动加 CNAME 记录
4. 等证书签发（全自动 HTTPS，一般几分钟）

### ⚠️ 两个真实踩过的坑（重点记）

| 坑 | 现象 | 解决 |
| --- | --- | --- |
| **CNAME 不能放根域** | 在 DigitalPlat DNS 面板给 `@`（zone apex）加 CNAME 直接报错 `CNAME records cannot be created at the zone apex`（RFC 1034 规定根域不能有 CNAME） | **用 `www` 子域**：给 `www` 加 CNAME 指向托管地址；访问时用 `www.你的域名` |
| **CNAME 值结尾必须带英文句点** | 填 `donkey-trace.pages.dev` 不带句点，面板自动拼成 `donkey-trace.pages.dev.lvlianchain.dpdns.org.`，解析到不存在的地址 | 值的**结尾手动补一个英文句点 `.`**，如 `donkey-trace.pages.dev.` |

### 续期

DigitalPlat 免费域名默认长期有效，面板内可查看到期时间，到期前在面板点续期即可（记得保留注册邮箱可用，收得到提醒）。

## 二、托管平台自带的免费域名（零注册，随开随用 ✅）

| 平台 | 送的域名 | 本项目用途 |
| --- | --- | --- |
| **Cloudflare Pages** | `项目名.pages.dev`（本项目：`donkey-trace.pages.dev`） | 前端静态托管，上传即得，自带 HTTPS，也是自定义域名的解析目标 |
| **GitHub Pages** | `用户名.github.io` | 备选静态托管 |
| **Vercel** | `项目名.vercel.app` | 备选（国内访问偶发不稳） |

这类"赠送域名"不用注册域名服务，部署时自动生成，适合当**备用地址**。

## 三、其他免费域名渠道（未在本项目实测，简要列出）

| 渠道 | 特点 | 注意 |
| --- | --- | --- |
| **eu.org** | 老牌，免费 `xxx.eu.org` 二级域名 | 人工审核，等几周到几个月 |
| **DuckDNS** | 免费 `xxx.duckdns.org`，动态域名 | 偏工具向，适合家用服务器 |
| **No-IP / afraid.org** | 免费动态域名 | 免费档需每月手动续 |
| **PP.ua** | 乌克兰官方免费二级域 | 需注册流程，政策偶有变动 |

> 想要"名字好听 + 解析稳定 + 能配 HTTPS"的组合，**DigitalPlat（dpdns.org 等）+ Cloudflare 托管**是当前免费方案里最省心的，本项目亲测跑通。

## 四、本项目域名体系一览

```
www.lvlianchain.dpdns.org   ← DigitalPlat 注册（主域名，答辩演示用）
        │ CNAME（结尾带句点！）
        ▼
donkey-trace.pages.dev      ← Cloudflare Pages 自动分配（备用地址）
        │
        ▼
Cloudflare CDN + 自动 HTTPS 证书
```
