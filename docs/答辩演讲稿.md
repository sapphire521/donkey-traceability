# 答辩演讲稿 — 项目介绍（4~5 分钟版）

> 场景：主要介绍功能与创新点，不铺垫背景。配合演示站 https://www.lvlianchain.dpdns.org（admin/123456）

## 开场（20 秒）

各位老师好，我演示的系统叫"驴链"——基于区块链的驴肉火烧全链路溯源管理系统。一句话概括：从一头驴的养殖档案，到餐桌上的驴肉火烧，每个环节的数据都上链存证，消费者扫码即可验真。下面我按业务流程演示功能。

## 功能走线（2.5 分钟，边演示边说）

**① 监管数据大屏（30 秒）**
先看监管端大屏：全市屠宰批次合格率 98.6%、各区县数据分布、实时预警——这是给市场监管部门用的驾驶舱，一目了然掌握全域驴肉产品质量态势。

**② 养殖端（30 秒）**
养殖场录入驴只档案：耳标号唯一标识、品种、免疫记录、出栏检疫——这是溯源链的起点，每头驴从出生就有"身份证"。

**③ 屠宰与运输（30 秒）**
屠宰环节按批次管理，检疫合格才能建批；运输环节记录车辆、温度、起止时间，批次和运单全部关联上链，环节之间责任边界清晰。

**④ 门店销售与溯源码（40 秒）**
门店收货、售出后生成溯源码。重点看这里（打开溯源查询）：消费者扫码，直接看到 H5 溯源报告——这批驴肉出自哪个养殖场、哪天屠宰、哪个批次、哪家门店，全链信息一次拉通。旁边是**区块链存证卡**，点核验，哈希比对通过，存证完整可信。

**⑤ 区块链账本（40 秒）**
这是系统的核心模块：每一笔业务操作都是一个区块，可以看到块高、时间戳、本块哈希和上一块哈希的链式关系。点"全链校验"——850 多个区块逐一重算 SHA-256 比对，校验通过。**（如条件允许加现场演示）**我现在去数据库里改一条历史数据，再点校验——校验失败，系统精确报出断链位置。这就是区块链防篡改能力的直接证明。

## 创新点（1 分钟，3 条，说完就收）

**第一，全链路一码贯通。** 耳标 → 屠宰批次 → 运输 → 门店 → 溯源码，五环节数据同一链上锚定，一个码正向可查来源、反向可召回，解决了传统溯源"各环节信息孤岛"的问题。

**第二，区块链防篡改存证真实可用。** 一交易一块、SHA-256 链式哈希、前向锚定、全链完整性校验，刚才的篡改实验就是技术验证；架构上账本服务做了抽象，可平滑接入 Hyperledger Fabric 真实联盟链。

**第三，工程完整度落地。** 前后端分离 45 个接口、19 张业务表、JWT 权限体系，并且已部署上线公网演示站（Cloudflare Pages + HTTPS + 自定义域名），任何设备扫码即可访问——不是只能在本机跑的"实验品"。

## 收尾（15 秒）

以上就是系统的核心功能与创新点。总结一句：**用区块链把"从牧场到餐桌"的每一环钉死在链上，让每一口驴肉火烧都查得到出处、验得了真伪。** 谢谢各位老师。
